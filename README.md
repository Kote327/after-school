# プロダクトゴール
- このアプリを通じてユーザーはグループで予定を確認できるようになる。

## 使い方

`index.html` をブラウザで開くと、グループの予定を確認できます。

- グループを作成して切り替え
- グループごとのメンバー追加と予定管理
- リスト表示と週表示を切り替え
- キーワード・カテゴリーで予定を絞り込み
- 「予定を追加」から予定を登録

グループ、メンバー、予定はブラウザの `localStorage` に保存されます。現時点では同じブラウザ内での利用を想定しており、複数端末との同期や招待リンクには対応していません。

ローカルサーバーを使う場合は、プロジェクトフォルダーで `python3 -m http.server 4173` を実行してください。
