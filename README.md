# つどい — グループ予定表

「つどい」は、グループごとの予定とメンバーをブラウザーで管理するシンプルな予定表です。HTML・CSS・JavaScriptで作られており、ビルドやパッケージのインストールは不要です。

## 起動方法

プロジェクトのフォルダーでローカルサーバーを起動します。

```bash
python3 -m http.server 4173
```

ブラウザーで <http://localhost:4173> を開いてください。終了するときは、サーバーを起動したターミナルで `Ctrl+C` を押します。

## できること

- グループの作成、切り替え、削除
- グループごとのメンバー追加
- 予定の追加（日付、時刻、カテゴリー、参加者）
- 予定のリスト表示と、今週の週表示の切り替え
- 予定名のキーワード検索とカテゴリー絞り込み
- 今日の予定数、参加メンバー数、次の予定、今後7日間の空いている日の表示

初回表示用に「デザインチーム」とサンプルのメンバー・予定が用意されています。作成した予定の参加者は名前やイニシャルを入力します。

## データの保存

グループ、メンバー、予定はブラウザーの `localStorage` に保存されます。データはそのブラウザー内にとどまり、別の端末やブラウザーとの同期、アカウント、招待リンク、サーバーへの共有には対応していません。ブラウザーのサイトデータを消去すると、保存した内容も消えます。

グループを削除すると、そのグループのメンバーと予定も一緒に削除されます。予定の編集・削除や、データのエクスポート・インポートは現在ありません。

## ファイル構成

- `index.html` — 画面とフォーム
- `style.css` — レイアウトとスタイル
- `script.js` — 表示、操作、ブラウザー内保存

画面のWebフォント読み込みにはインターネット接続が必要です。接続できない場合も、ブラウザーの代替フォントで表示されます。
